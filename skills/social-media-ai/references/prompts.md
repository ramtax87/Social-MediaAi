# Prompts to copy into Codex

These are natural-language requests; the agent handles commands and configuration. Choose the one you need. For an already installed skill, `$social-media-ai` selects it.

## First-time setup from the repository

```text
Find https://github.com/ramtax87/Social-MediaAi and follow START_HERE.md.
Install its social-media-ai skill and do the technical setup for me.
Ask one simple question at a time, connect each account separately,
show me sample posts, and ask before new permissions, paid services,
external media hosting, or activating live posting. Remember my choices.
Start now with the missing information you need from me.
```

## Continue a saved setup

```text
Use $social-media-ai to continue my saved setup. Read my existing profile
and approvals, check what is still missing, and ask the next question.
Do not reconnect accounts or reset my queue.
```

If a new chat doesn't know the workspace, add its path or provide it when asked.

## Preview without publishing

```text
Use $social-media-ai to prepare three sample posts from my configured
folder. Show the cleaned media, captions, target accounts, and proposed
times. Keep them as drafts until I approve them.
```

## Approve the displayed batch

Use this only after reviewing the actual batch and times:

```text
I approve the exact posts and times you just showed. Schedule that batch
for the displayed accounts. Keep future new posts in review mode.
```

## Enable automatic posting

Use this after the agent shows the folder, accounts, edits, caption rules, schedule, limits, and service access:

```text
I approve the displayed automatic-posting plan. Activate it for those
accounts using those rules and limits. You may prepare and post future
items within that scope without asking for each one. Ask before adding
accounts, changing the scope, or incurring new costs. Confirm the real
schedule and its next runs when it is active.
```

## Add one account

```text
Use $social-media-ai to add another social account. Ask which one,
connect only that account, and verify it before adding it to my posting
plan. Keep my existing accounts and settings.
```

## Change the schedule

```text
Use $social-media-ai to help change my posting schedule. Ask what days,
times, and timezone I want, then show how this affects already queued
posts before moving them. Preserve all published-post history.
```

## Pause all posting

```text
Use $social-media-ai to pause all posting now. Pause the recurring task
and stop my pending posts already scheduled at the provider. Keep my
original files and published history. Report anything you could not stop.
```

## Resume after a pause

```text
Use $social-media-ai to resume my approved posting plan. Recheck account
access and the remote queue first. Skip missed slots rather than posting
a backlog all at once, and show the next scheduled runs.
```

## Status or repair

```text
Use $social-media-ai to show my connected accounts, drafts needing
approval, scheduled times, and confirmed published links. Check failed
or uncertain submissions without blindly retrying them. Guide me through
one missing connection or permission at a time.
```
