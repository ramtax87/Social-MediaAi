# Social-MediaAi agent entrypoint

For a user asking to **install, set up, or use** this repository, read [START_HERE.md](START_HERE.md), then carry out the guided setup. A repository URL or “find this repo and set it up for me” is enough to begin discovery and local preparation. Ask one question at a time; connect accounts separately. Continue through the authorized work instead of stopping after a summary of the README.

For a user asking to **develop, review, or change the repository**, work on the requested files. Do not start onboarding or connect the developer's personal social accounts. Keep personal media, credentials, profiles, and queue databases outside Git. Validate changed helpers with the relevant tests in `tests/`; the suite runs with `python3 -m unittest discover -s tests -v`. Test media should be temporary fixtures, never real social posts.

The public repository is `https://github.com/ramtax87/Social-MediaAi`. The installable skill is `skills/social-media-ai`. Explicit user instructions and already granted authorization take precedence over default suggestions in these guides.
